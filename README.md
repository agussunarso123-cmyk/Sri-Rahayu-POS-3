# Sri Rahayu POS

Aplikasi kasir Android untuk usaha kuliner.

Fitur awal:
- Kasir, keranjang, total otomatis, dan transaksi.
- Katalog menu, harga, stok, serta foto dari galeri.
- Ringkasan dan riwayat penjualan.
- Pengelolaan beberapa cabang dan pilihan cabang aktif.
- Penyimpanan lokal offline-first.
- Build APK otomatis melalui GitHub Actions.

## Membuat APK
1. Buka tab Actions.
2. Pilih workflow Build Sri Rahayu POS APK.
3. Tekan Run workflow atau tunggu build otomatis.
4. Setelah selesai, buka run yang berhasil dan unduh artifact sri-rahayu-pos-release.
5. Ekstrak ZIP, lalu pasang app-release.apk di Android.

Catatan: versi awal menyimpan data pada satu perangkat. Sinkronisasi antarperangkat/cabang, login karyawan, backup cloud, dan printer Bluetooth merupakan tahap lanjutan.
